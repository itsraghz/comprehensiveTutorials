# Spring Data JPA

This repository contains the step by step instructions to set up a Spring Boot Project with Spring Data JPA, with H2 database, with the real time example of a Student Management System (SMS) to demonstrate the CRUD features - Create, Read, Update and Delete.

This repository will also have some exercises for the students to perform in the session (live lecture if any), along with the answers with explanation

## Set up

This entire tutorial is presented in a Web based manner with a Bootstrap Framework, where each topic is explained in a Tab based Navigation and Menu. 

## Precursory 

A precursory explanation to demonstrate and justify the benefits offered by Spring Data JPA, the following will be discussed precisely.

* JDBC (Java Database Connectivity) with a plain maven project with the H2 database
* JPA (Java Persistence API) with Hibernate as the ORM implementation
* Basics of Spring Core with an explanation of DI (Dependency Injection) 

## Tech Stack

* JDK 17 or above
* H2 database (latest)
* Spring Framework 6
* Spring Boot 3
* IDE - Intellj IDEA (Community Edition) / STS (Spring Tool Suite)
