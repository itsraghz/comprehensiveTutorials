Introduction to Spring Data JPA

Spring Data JPA is part of the larger Spring Data family that makes it easy to implement JPA-based repositories. It provides a layer of abstraction that simplifies data access by reducing the amount of boilerplate code needed.

Key benefits of Spring Data JPA include:

  • Significantly reduces boilerplate code for data access layers
  • Provides convenient abstractions for paging and sorting
  • Easy implementation of custom query methods
  • Integration with Spring's transaction management
  • Support for auditing and dynamic queries

JDBC (Java Database Connectivity)

Before JPA and Spring Data, developers used JDBC to interact with databases. JDBC is a Java API that allows Java applications to interact with relational database systems.

Key JDBC Concepts
  • Direct SQL execution through Connection, Statement, and ResultSet objects
  • Manual transaction management
  • Explicit resource handling (connections, statements)
  • Verbose error handling with try-catch blocks
Sample JDBC Code:
Connection conn = null;
Statement stmt = null;
try {
    conn = DriverManager.getConnection(DB_URL, USER, PASS);
    stmt = conn.createStatement();
    String sql = "SELECT id, name, age FROM students";
    ResultSet rs = stmt.executeQuery(sql);
    
    while(rs.next()) {
        int id = rs.getInt("id");
        String name = rs.getString("name");
        int age = rs.getInt("age");
        // Process data
    }
    rs.close();
} catch(SQLException se) {
    // Handle errors
} finally {
    // Close resources
    try {
        if(stmt!=null) stmt.close();
    } catch(SQLException se) {}
    try {
        if(conn!=null) conn.close();
    } catch(SQLException se) {}
}

JPA and Hibernate

JPA (Java Persistence API) is a specification for ORM (Object-Relational Mapping) in Java. Hibernate is one of the most popular implementations of JPA.

JPA Key Features
  • Standard ORM specification for Java
  • Entity management and mapping
  • JPQL (Java Persistence Query Language)
  • Persistence context and caching
  • Criteria API for type-safe queries
Hibernate Benefits
  • Mature, feature-rich JPA implementation
  • Advanced caching capabilities
  • Lazy loading and eager fetching
  • Hibernate Query Language (HQL)
  • Session management
Sample JPA Entity:
@Entity
@Table(name = "students")
public class Student {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(name = "first_name", nullable = false)
    private String firstName;
    
    @Column(name = "last_name")
    private String lastName;
    
    @Column(name = "email", unique = true)
    private String email;
    
    // Getters and setters
}

Spring Core and Dependency Injection

Spring Core provides the fundamental functionality of the Spring Framework, including dependency injection and inversion of control.

Key Spring Core Concepts:
  • Inversion of Control (IoC): The Spring container is responsible for instantiating, configuring, and assembling objects (beans).
  • Dependency Injection (DI): Objects are given their dependencies at creation time by the framework rather than looking up dependencies themselves.
  • Bean lifecycle management: Spring manages the complete lifecycle of beans from instantiation to destruction.
Types of Dependency Injection:
Constructor Injection
@Service
public class StudentService {
    private final StudentRepository repository;
    
    @Autowired
    public StudentService(StudentRepository repository) {
        this.repository = repository;
    }
}
Setter Injection
@Service
public class StudentService {
    private StudentRepository repository;
    
    @Autowired
    public void setRepository(StudentRepository repository) {
        this.repository = repository;
    }
}

Spring Data JPA Fundamentals

Spring Data JPA simplifies the implementation of JPA-based repositories by providing a higher level of abstraction.

  • Repository Interfaces: Define an interface extending Spring Data repositories to get basic CRUD operations
  • Query Methods: Define methods following naming conventions to automatically generate queries
  • Custom Queries: Use @Query annotation for more complex queries
  • Paging and Sorting: Built-in support for pagination and sorting
  • Auditing: Track who created or modified entities and when

Spring Data JPA provides a hierarchy of repository interfaces:

  • Repository: Marker interface with no methods
  • CrudRepository: Basic CRUD operations
  • PagingAndSortingRepository: Adds methods for pagination and sorting
  • JpaRepository: JPA-specific methods including flushing the persistence context and batch operations

Spring Data JPA allows you to define query methods by simply declaring method signatures in repository interfaces:

public interface StudentRepository extends JpaRepository<Student, Long> {
    List<Student> findByLastName(String lastName);
    List<Student> findByFirstNameAndEmail(String firstName, String email);
    Student findTopByOrderByGpaDesc();
    List<Student> findByAgeBetween(int minAge, int maxAge);
    List<Student> findByEnrollmentDateAfter(Date date);
}

Spring Data JPA parses the method names and automatically generates the appropriate JPQL queries.

For complex queries, use the @Query annotation:

public interface StudentRepository extends JpaRepository<Student, Long> {
    @Query("SELECT s FROM Student s WHERE s.gpa > :minGpa")
    List<Student> findHighPerformingStudents(@Param("minGpa") double minGpa);
    
    @Query("SELECT s FROM Student s JOIN s.courses c WHERE c.id = :courseId")
    List<Student> findStudentsEnrolledInCourse(@Param("courseId") Long courseId);
    
    @Query(value = "SELECT * FROM students WHERE graduation_year = :year", nativeQuery = true)
    List<Student> findByGraduationYearNative(@Param("year") int year);
}

Spring Data JPA provides built-in support for pagination and sorting:

// In the repository
public interface StudentRepository extends JpaRepository<Student, Long> {
    Page<Student> findByLastName(String lastName, Pageable pageable);
    List<Student> findByFirstName(String firstName, Sort sort);
}

// In the service/controller
// Pagination example
PageRequest pageRequest = PageRequest.of(0, 10, Sort.by("lastName").ascending());
Page<Student> studentsPage = studentRepository.findByLastName("Smith", pageRequest);

// Sorting example
List<Student> students = studentRepository.findByFirstName("John", 
    Sort.by("gpa").descending().and(Sort.by("lastName")));

API Classes & Methods

Spring Data JPA provides a rich set of interfaces and classes to simplify database operations.

Core Interfaces

Repository Interfaces
  • Repository<T, ID>

    Marker interface that captures the domain type and ID type. Primarily used as a marker to capture the types.

  • CrudRepository<T, ID>

    Provides CRUD functions:

    save(), findById(), findAll(), count(), delete(), existsById()
  • PagingAndSortingRepository<T, ID>

    Adds methods to ease paginated access:

    findAll(Pageable), findAll(Sort)
  • JpaRepository<T, ID>

    JPA-specific extension adding:

    flush(), saveAndFlush(), deleteInBatch(), deleteAllInBatch()
Support Classes
  • Sort

    Class for sorting queries with methods:

    by(), ascending(), descending(), and()
  • Pageable & PageRequest

    Interfaces and implementation for pagination:

    PageRequest.of(int page, int size)
  • Page<T>

    Interface for a page of results with methods:

    getTotalPages(), getTotalElements(), getContent(), hasNext()
  • Example & ExampleMatcher

    Classes for query by example (QBE) functionality:

    Example.of(), matching(), withIgnoreCase()

Query Method Patterns

Keyword Sample Method JPQL Query
And findByLastNameAndFirstName ... where x.lastName = ?1 and x.firstName = ?2
Or findByLastNameOrFirstName ... where x.lastName = ?1 or x.firstName = ?2
Between findByAgeBetween ... where x.age between ?1 and ?2
LessThan findByAgeLessThan ... where x.age < ?1
GreaterThan findByAgeGreaterThan ... where x.age > ?1
IsNull, IsNotNull findByMiddleNameIsNull ... where x.middleName is null
Like, NotLike findByFirstNameLike ... where x.firstName like ?1
StartingWith findByFirstNameStartingWith ... where x.firstName like ?1 + '%'
OrderBy findByAgeOrderByLastNameDesc ... where x.age = ?1 order by x.lastName desc
