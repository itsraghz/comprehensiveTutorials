Introduction to Spring Data JPA

Spring Data JPA is part of the larger Spring Data family that makes it easy to implement JPA-based repositories. It provides a layer of abstraction that simplifies data access by reducing the amount of boilerplate code needed.

Key benefits of Spring Data JPA include:

  • Significantly reduces boilerplate code for data access layers
  • Provides convenient abstractions for paging and sorting
  • Easy implementation of custom query methods
  • Integration with Spring's transaction management
  • Support for auditing and dynamic queries

JDBC (Java Database Connectivity)

Before JPA and Spring Data, developers used JDBC to interact with databases. JDBC is a Java API that allows Java applications to interact with relational database systems.

Key JDBC Concepts
  • Direct SQL execution through Connection, Statement, and ResultSet objects
  • Manual transaction management
  • Explicit resource handling (connections, statements)
  • Verbose error handling with try-catch blocks
Sample JDBC Code:
Connection conn = null;
Statement stmt = null;
try {
    conn = DriverManager.getConnection(DB_URL, USER, PASS);
    stmt = conn.createStatement();
    String sql = "SELECT id, name, age FROM students";
    ResultSet rs = stmt.executeQuery(sql);
    
    while(rs.next()) {
        int id = rs.getInt("id");
        String name = rs.getString("name");
        int age = rs.getInt("age");
        // Process data
    }
    rs.close();
} catch(SQLException se) {
    // Handle errors
} finally {
    // Close resources
    try {
        if(stmt!=null) stmt.close();
    } catch(SQLException se) {}
    try {
        if(conn!=null) conn.close();
    } catch(SQLException se) {}
}

JPA and Hibernate

JPA (Java Persistence API) is a specification for ORM (Object-Relational Mapping) in Java. Hibernate is one of the most popular implementations of JPA.

JPA Key Features
  • Standard ORM specification for Java
  • Entity management and mapping
  • JPQL (Java Persistence Query Language)
  • Persistence context and caching
  • Criteria API for type-safe queries
Hibernate Benefits
  • Mature, feature-rich JPA implementation
  • Advanced caching capabilities
  • Lazy loading and eager fetching
  • Hibernate Query Language (HQL)
  • Session management
Sample JPA Entity:
@Entity
@Table(name = "students")
public class Student {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(name = "first_name", nullable = false)
    private String firstName;
    
    @Column(name = "last_name")
    private String lastName;
    
    @Column(name = "email", unique = true)
    private String email;
    
    // Getters and setters
}

Spring Core and Dependency Injection

Spring Core provides the fundamental functionality of the Spring Framework, including dependency injection and inversion of control.

Key Spring Core Concepts:
  • Inversion of Control (IoC): The Spring container is responsible for instantiating, configuring, and assembling objects (beans).
  • Dependency Injection (DI): Objects are given their dependencies at creation time by the framework rather than looking up dependencies themselves.
  • Bean lifecycle management: Spring manages the complete lifecycle of beans from instantiation to destruction.
Types of Dependency Injection:
Constructor Injection
@Service
public class StudentService {
    private final StudentRepository repository;
    
    @Autowired
    public StudentService(StudentRepository repository) {
        this.repository = repository;
    }
}
Setter Injection
@Service
public class StudentService {
    private StudentRepository repository;
    
    @Autowired
    public void setRepository(StudentRepository repository) {
        this.repository = repository;
    }
}

Spring Data JPA Fundamentals

Spring Data JPA simplifies the implementation of JPA-based repositories by providing a higher level of abstraction.

  • Repository Interfaces: Define an interface extending Spring Data repositories to get basic CRUD operations
  • Query Methods: Define methods following naming conventions to automatically generate queries
  • Custom Queries: Use @Query annotation for more complex queries
  • Paging and Sorting: Built-in support for pagination and sorting
  • Auditing: Track who created or modified entities and when

Spring Data JPA provides a hierarchy of repository interfaces:

  • Repository: Marker interface with no methods
  • CrudRepository: Basic CRUD operations
  • PagingAndSortingRepository: Adds methods for pagination and sorting
  • JpaRepository: JPA-specific methods including flushing the persistence context and batch operations

Spring Data JPA allows you to define query methods by simply declaring method signatures in repository interfaces:

public interface StudentRepository extends JpaRepository<Student, Long> {
    List<Student> findByLastName(String lastName);
    List<Student> findByFirstNameAndEmail(String firstName, String email);
    Student findTopByOrderByGpaDesc();
    List<Student> findByAgeBetween(int minAge, int maxAge);
    List<Student> findByEnrollmentDateAfter(Date date);
}

These method names are automatically parsed and converted to SQL queries by Spring Data JPA.

Configuring Spring Data JPA involves several steps:

  • Dependencies: Add Spring Data JPA and a database driver to your project
  • DataSource Configuration: Configure the database connection
  • EntityManager Configuration: Set up the JPA EntityManagerFactory
  • Repository Configuration: Enable the repository interfaces

In Spring Boot, much of this is auto-configured when you add the right starter dependencies:

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>runtime</scope>
</dependency>

Spring Data JPA API Classes & Methods

Spring Data JPA provides a rich set of interfaces and classes to simplify database operations.

Core Repository Interfaces
  • Repository

    Marker interface that captures the domain type and ID type. Primarily used for type information.

  • CrudRepository

    Provides CRUD functionality:

    • save(entity) - Save an entity
    • findById(id) - Find by primary key
    • existsById(id) - Check if entity exists
    • findAll() - Get all entities
    • count() - Count entities
    • delete(entity) - Delete an entity
  • PagingAndSortingRepository

    Adds pagination and sorting functionality:

    • findAll(Pageable pageable) - Get entities with pagination
    • findAll(Sort sort) - Get sorted entities
  • JpaRepository

    Adds JPA-specific methods:

    • flush() - Flush pending changes
    • saveAndFlush(entity) - Save and flush
    • deleteInBatch(entities) - Batch delete
    • deleteAllInBatch() - Delete all in one query
Query Methods and Annotations
Query Creation

Method names are parsed to create queries automatically:

// Finds all students with the given last name
findByLastName(String lastName)

// Finds students with last name like pattern
findByLastNameLike(String pattern)

// Greater than or equal to
findByAgeGreaterThanEqual(Integer age)

// Limit results
findTop10ByOrderByGpaDesc()
@Query Annotation

For complex queries, use the @Query annotation:

@Query("SELECT s FROM Student s WHERE s.gpa > ?1")
List findStudentsWithGpaGreaterThan(Double gpa);

@Query("SELECT s FROM Student s WHERE s.firstName = :name OR s.lastName = :name")
List findByFirstOrLastName(@Param("name") String name);
Other Important APIs
  • Sort: For specifying sort criteria
  • Pageable/PageRequest: For pagination
  • Specification: For dynamic queries (JPA Criteria API)
  • Example/ExampleMatcher: For query-by-example
// Sorting
Sort sort = Sort.by(Sort.Direction.DESC, "lastName");

// Pagination
Pageable pageable = PageRequest.of(0, 20, sort);
Page studentPage = studentRepository.findAll(pageable);

Project Structure

The sample application follows a standard Spring Boot project structure:

  • model - Entity classes
  • repository - Spring Data JPA repositories
  • service - Service layer with business logic
  • controller - REST controllers

public interface StudentRepository extends JpaRepository {
    
    // Find by name
    List findByFirstName(String firstName);
    List findByLastName(String lastName);
    
    // Find by email (unique)
    Optional findByEmail(String email);
    
    // Find by age range
    List findByAgeBetween(Integer minAge, Integer maxAge);
    
    // Find by GPA with sorting
    List findByGpaGreaterThanEqual(Double minGpa, Sort sort);
    
    // Find by department
    List findByDepartmentName(String departmentName);
    
    // Count students in each department
    @Query("SELECT s.department.name, COUNT(s) FROM Student s GROUP BY s.department.name")
    List countStudentsByDepartment();
    
    // Find top performers
    @Query("SELECT s FROM Student s ORDER BY s.gpa DESC")
    List findTopPerformers(Pageable pageable);
}

        if (student.getDepartment() != null && student.getDepartment().getId() != null) {

            student.setDepartment(department);

            studentRepository.findByEmail(studentDetails.getEmail())
                .ifPresent(s -> {

@RestController
@RequestMapping("/api/students")
public class StudentController {
    
    private final StudentService studentService;
    
    @Autowired
    public StudentController(StudentService studentService) {
        this.studentService = studentService;
    }
    
    @GetMapping
    public List getAllStudents() {
        return studentService.getAllStudents();
    }
    
    @GetMapping("/{id}")
    public ResponseEntity getStudentById(@PathVariable Long id) {
        Student student = studentService.getStudentById(id);
        return ResponseEntity.ok(student);
    }
    
    @PostMapping
    public ResponseEntity createStudent(@Valid @RequestBody Student student) {
        Student newStudent = studentService.createStudent(student);
        return ResponseEntity
            .created(URI.create("/api/students/" + newStudent.getId()))
            .body(newStudent);
    }
    
    @PutMapping("/{id}")
    public ResponseEntity updateStudent(
            @PathVariable Long id, 
            @Valid @RequestBody Student studentDetails) {
        Student updatedStudent = studentService.updateStudent(id, studentDetails);
        return ResponseEntity.ok(updatedStudent);
    }
    
    @DeleteMapping("/{id}")
    public ResponseEntity deleteStudent(@PathVariable Long id) {
        studentService.deleteStudent(id);
        return ResponseEntity.noContent().build();
    }
    
    @GetMapping("/top-performers")
    public List getTopPerformers(@RequestParam(defaultValue = "10") int count) {
        return studentService.findTopPerformers(count);
    }
}
